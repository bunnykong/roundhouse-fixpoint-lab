# Reproduce the bounded observation

Run `python3 rerun.py saved` first; it invokes no analyzer. Every fresh run is a new unscored condition.
Acquire public inputs only, at the commits in [pins.json](pins.json). Original command/exit/flag records remain
in the [manifest](manifest.json); do not infer a completed app stage from a focused control.

The portable source-preserving runtime witness is `native/ownership.rb`. Supply public Forem/Mastodon inputs
at the pinned commits, plus the retained pinned Rails method snippets indexed by the manifest.

```sh
PUBLIC_INPUTS=./inputs ruby native/ownership.rb
```

Use CRuby 4.0.7. These are finite collaborators and method-boundary executions, not full app boots.
The saved reducer executes the retained type-set interpreter on every changed row, then recounts the five
narrowing classes and the independent sample admission evidence. Supplemental actual Rails components
confirm sampled HTML/API return classes; they do not establish universal request reachability.
